一、系统概述

1.1 产品定位

MindExam考试平台是面向培训与考核场景的题库与考务管理系统。核心链路为：

考核大纲（结构化分类） → 题库（按大纲末级分类挂题） → 试卷（按分类范围抽题/选题组卷） → 考试（暂未开放）

平台同时提供机构、账号、角色、字典等基础数据与系统配置能力。

  • 保持当前页，保留已输入的账号（密码按安全惯例可清空）。

4.4 会话与单设备登录

场景系统行为

主动退出登录清除登录态，跳转登录页并提示「已退出登录」
三类回跳提示均为顶部轻提示，进入登录页时展示一次，刷新后不再重复。

字段规则
试卷名称必填；≤30 字；不可重名；输入内容实时同步到右侧试卷标题（为空时显示「未命名试卷」）
关联大纲必填；仅列出启用的大纲；切换大纲会清空分类范围、已抽题目与各题型题数（分值保留）
分类范围必填；点击输入框展开该大纲的分类树；勾选父级联动全选子级；支持跨分类多选；已选时输入框显示首个勾选的一级分类名；未选大纲时不可用
题型配置（题数）仅正整数；右侧显示「/ 可用上限」；智能抽题模式下可编辑，手动选题模式下只读（由已选题目反推）
题型配置（分值）仅正整数；每种有题目的题型必须 >0
总分只读，= Σ（题数 × 每题分值），随配置实时更新
状态单选启用/停用，默认启用

补题打开「从题库选题」抽屉，勾选后追加到试卷
空态未抽题时展示空态插画 + 「暂无数据」

4.4 从题库选题抽屉

区域规则
头部标题「从题库选题」+ 关闭按钮

六、核心流程

6.1 智能抽题

配置名称 / 大纲 / 分类范围 / 各题型题数与分值
   → 点击「开始抽题」
        ├─ 校验失败 → 对应行报错
        ├─ 已有题目 → 二次确认「重新抽题将替换当前内容，请确认是否重新抽题」
        └─ 通过 → 按各题型题数从分类范围内随机抽取 → 提示「抽题成功，共 N 题」
                  → 右侧清单按题型分组展示 → 题数、分值、总分联动

6.2 手动选题

点击「手动选题」→ 打开抽屉
   → 按题型/题干筛选 → 勾选题目（可跨页保持勾选）
   → 「加入试卷」→ 按题型归入右侧清单 → 题数自动回写为各题型已选数量
   → 重复「补题」可继续追加

6.3 保存为草稿 / 发布

点击「保存为草稿」→ 校验 → 直接保存（状态=草稿）→ 提示「操作成功」→ 返回列表
点击「发布」→ 校验 → 二次确认 → 保存（状态=当前选择）→ 提示「操作成功」→ 返回列表
网络异常：提示「网络异常，请稍后重试」，页面保持，配置与已选题目不丢失

一、页面概述

1.1 页面目标

维护角色及其两级权限：数据权限（能看到哪些机构的数据）与 菜单权限（能用哪些功能）。角色是账号的功能权限来源，账号通过绑定角色获得权限。

1.2 入口与出口

方向说明
入口左侧菜单 基础数据 → 角色管理
出口无二级页，配置均在弹窗内完成

1.3 使用角色

基础数据管理员、平台管理员。

二、业务对象

字段说明必填规则
角色名称角色唯一标识是≤30 字；全局唯一（编辑排除自身）；改名后同步更新账号表中引用该角色的账号
状态启用 / 停用是默认启用；停用后不可再分配给账号
数据权限可查看的机构范围是机构多选，至少选择 1 个；全选时记为「全部数据权限」
权限配置可访问的菜单是按菜单分组勾选，至少选择 1 项
关联账号该角色下的账号数量—系统统计，>0 时禁止删除角色
更新时间最近一次修改时间—YYYY.MM.DD HH:MM:SS

一、页面概述

1.1 页面目标

集中维护系统中的枚举数据（题型、状态、分类标签等）。采用「左侧字典类型 + 右侧字典项」的左右分栏结构，支持类型级与条目级的增删改查，以及条目排序。

1.2 入口与出口

方向说明
入口左侧菜单 系统配置 → 字典管理
出口无二级页，全部操作在弹窗内完成

1.3 使用角色

系统配置管理员、平台管理员。

二、业务对象

2.1 字典类型

字段说明必填规则
类型名称类型展示名是≤30 字；全局唯一
类型编码程序引用标识是1–50 位，仅英文字母、数字、下划线；全局唯一；建议创建后不可修改
字典分类业务 / 内置是业务类可自由维护；内置类为系统依赖，修改需谨慎（当前仅作标签区分）
状态启用 / 停用是默认启用
条目数该类型下字典项数量—系统统计，卡片上展示

2.2 字典项

字段说明必填规则
标签展示文案是≤30 字；同一类型内唯一
键值程序取值是1–50 位，仅英文字母、数字、下划线；同一类型内唯一；创建后不可修改
排序展示顺序是即列表位置，取值范围 1 ~ 当前类型条目总数（新建时可排到末位）
状态启用 / 停用是默认启用

2.3 排序语义

  • 排序号等于「第几位」，不表示权重差值，因此不允许跳号与空档。
  • 例如某类型共 5 项，则排序号只能取 1–5；把第 3 项改为 1，则原 1、2 项顺延为 2、3，整体保持 1..n 连续。

5.1 字段规则

5.2 排序交互

交互规则
默认值新建：末位（当前项数 + 1）；编辑：回显原排序号
提示文案字段下方动态显示「当前共 N 项，排序号可选 1-M，数字越小越靠前」
输入过滤仅数字，自动去除非数字与前导零；允许暂时为空，失焦补全为 1
步进器− / + 按钮，到上下边界自动禁用置灰
落位规则保存时把该项插入到第 N 位，其余项顺延重排，整体保持 1..n 连续
删除后剩余项按当前顺序重新编号，保持连续无空档
